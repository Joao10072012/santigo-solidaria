
# 🤝 Santiago Solidária

**Informação, ajuda e conexão para quem foi atingido por temporais em Santiago - RS.**

## 🌐 Acesse o projeto

🔗 [Clique aqui para testar o site Santiago Solidária](https://joao10072012.github.io/santigo-solidaria/)

## 📌 Sobre o projeto

O Santiago Solidária é um site desenvolvido para conectar pessoas afetadas por temporais a serviços de assistência, abrigos e doações.

A proposta é facilitar o acesso a informações importantes, permitindo que famílias solicitem ajuda e encontrem pontos de atendimento.

## 🎯 Objetivos

- 🆘 Facilitar a solicitação de ajuda para famílias afetadas.
- 📍 Disponibilizar informações sobre abrigos e pontos de atendimento.
- 🚨 Divulgar contatos de emergência.
- 📦 Incentivar a arrecadação e distribuição de doações.
- 🤝 Promover a solidariedade e a colaboração entre a comunidade.

## ✨ Funcionalidades

- **Página inicial:** apresentação do projeto e informações sobre o temporal.
- **Preciso de ajuda:** formulário para informar necessidades e dados de contato.
- **Encontrar ajuda:** seção com informações sobre abrigos e pontos de atendimento.
- **Emergência:** atalhos para serviços de emergência.
- **Informações importantes:** divulgação de locais de abrigo, contatos e itens para doação.

## 🛠️ Tecnologias utilizadas

- HTML5 — estrutura do site.
- CSS3 — estilização e layout.
- JavaScript — interatividade e funcionalidades.

## 🚀 Como executar localmente

1. Clone ou baixe o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Confira se o arquivo `index.html` está conectado ao `style.css`.
4. Abra o `index.html` no navegador ou utilize a extensão Live Server.

## 🚨 Contatos de emergência

- **193 — Bombeiros**
- **192 — SAMU**
- **190 — Brigada Militar**

Em situações de risco imediato, entre em contato diretamente com o serviço de emergência adequado.

## 🔒 Privacidade e segurança

Os dados informados no formulário devem ser utilizados somente para a finalidade de atendimento e encaminhamento das solicitações, com medidas adequadas de proteção.

**Importante:** para que as solicitações sejam efetivamente recebidas, o formulário precisa estar conectado a um mecanismo de envio ou armazenamento de dados. Os contatos e locais de atendimento devem ser verificados antes da divulgação pública.
